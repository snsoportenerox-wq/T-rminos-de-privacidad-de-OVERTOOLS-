Política de privacidad

Última actualización: 19 de noviembre de 2026.

1. Datos que podemos recibir

Al iniciar sesión con Discord, el sitio puede recibir tu identificador, nombre de usuario y avatar mediante el permiso identify.

2. Finalidad

Estos datos se utilizan para identificar tu sesión y mostrar tu perfil.

3. Registro de inicios de sesión

Si el administrador configura un webhook de auditoría, se puede registrar el nombre de usuario, ID de Discord, avatar y fecha del inicio de sesión. No se deben enviar tokens ni códigos de autorización.

4. Proveedores

La autenticación depende de Discord, la verificación anti-bots de Cloudflare Turnstile y el alojamiento de Netlify. Si se habilitan tickets, se podrá utilizar Supabase para almacenar conversaciones y datos asociados.

5. Contacto

Para consultas sobre privacidad, contacta con el equipo desde el servidor de soporte.
